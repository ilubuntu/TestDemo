# 云测规则验证用例工程

四个 HarmonyOS 应用工程（compatibleSdkVersion / targetSdkVersion 均为 **26.0.0**，API 26），用于上传云测试验证 UX 规则的检出能力：case-a/b/c 覆盖 11 条 UX 规则，case-d 覆盖一多适配 3 类典型问题（截断 / 键盘遮挡 / 组件重叠）。

## 工程与规则映射

### case-a「避让与留白」 com.ct.casea · 主测 Mate 60

| 页面 | 规则 | 违规机制 |
|---|---|---|
| Index 首页（汇率速查） | 导航条适配 | 沉浸式全屏布局下，底部深色操作栏贴物理底边，56vp「查询」按钮直接压在导航条区域（控件遮挡 + 背景不融合） |
| StatusBarCutPage | 状态栏 | 沉浸式下深色海报（poster2 + 0.85 深色遮罩）从 y=0 绘制，状态栏保持系统默认样式，深色背景上图标对比不足、状态栏区域与页面割裂 |
| CutoutPage | 挖孔区 | 沉浸式下 44vp 白底圆角搜索框从物理顶部 y=0 居中开始，横穿状态栏/挖孔区 |
| SparsePage | 留白率 >0.7 | 全屏仅中央一张小卡片（icon +「暂无数据」），留白率≈0.95 |
| DensePage | 留白率 <0.1 | 设置页 12 条满宽设置项：两侧贴边零留白、行距紧凑、交替底色，设计元素 box≈窗口 |

### case-b「信息量」 com.ct.caseb · 主测 Pura X Max

| 页面 | 规则 | 违规机制 |
|---|---|---|
| Index 首页（环球资讯） | 单图信息量 | 单张大图宽度顶满、高度按源图比例 1080:1300 等比自适应不裁切：折叠态高≈屏宽×1.2 超 1/2 上限；展开态高≈屏宽×1.2 超过整屏，首屏只见图片（外层 Scroll 保证下方内容可滚动到达） |
| Index 首页 | 宫格图信息量 | 国旗宫格行固定 20vp 高，远低于 1/10 屏高下限 |
| DetailPage | 上下图文信息量 | 海报图高 70% 屏（详情页上限 3/5），下方标题正文 |
| SheetPage | 弹出框大小适中 | 进入 100ms 自动弹 bindSheet「应用信息与协议」半模态；高度 = 屏宽 100%（px2vp 转换）：折叠态 ≈405vp（正常），展开态 ≈647vp（折叠态 1.6 倍 > 1.2 上限） |

### case-c「形态切换」 com.ct.casec · 主测 Pura X Max

| 页面 | 规则 | 违规机制 |
|---|---|---|
| BrokenLayoutPage | 布局基础 | 3×320vp 固定宽国旗货币卡 Row 不换行（折叠/展开屏宽下均截断）+ 固定坐标 HOT 角标（形态切换后相对内容错位） |
| StateLossPage | 开合连续性 | 设置页 20 项（开关状态存子组件 @Local）；mediaquery 官方断点（600vp）if/else 切换单列/双列（lanes 2）——折叠/展开时组件树销毁重建：开关回默认关、滚动位置丢失、单列 20 行变双列 10 行内容整体偏移 |
| BigTextPage | 图标文字大小 | 零监听纯百分比自适应：大标题 width('60%') + 单行字号自适应撑满（min 20/max 64 fp）、副标题 width('80%')、图标 width('25%')——物理尺寸随屏宽等比放大 1.6 倍 > 1.2 上限 |

### case-d「一多适配典型问题」 com.ct.cased · 主测 Pura X Max

个人中心/意见反馈/服务中心三个页面，全部用"直板机正常、折叠屏展开出问题"的机型区分原则：直板机（sm 断点，约 405×896vp）完全正常；Pura X Max 展开态（lg 断点，窗口 vp 高度骤减）全部复现。

| 页面 | 规则 | 违规机制 |
|---|---|---|
| S1TruncatePage | 截断与不可见 | 个人中心页 24%/10%/34%/28% 四段百分比高度分区 + 区内固定尺寸内容（96vp 头像、48vp 宫格图标、72vp 列表图），展开态各分区 vp 高度被压缩，内容截断/不可见 |
| S2KeyboardPage | 键盘遮挡 | 意见反馈页进入 500ms 自动聚焦 TextArea 拉起键盘，页面未做任何键盘避让，展开态键盘遮挡输入区与提交按钮 |
| S3OverlapPage | 组件重叠 | 服务中心页卡片区 height('50%') 内放固定 46% 宽 × 3 行卡片 + 底部系统公告条/运营条，断点变化时各区域挤压重叠 |

## 如何测试（云测验证流程）

1. **上传云测**：上传Release签名包，测试类型选 UX 测试（category=24）
2. **设备选择**：
   - case-a：Mate 60（避让与留白类规则）
   - case-b / case-c / case-d：必须含 Pura X Max（信息量、形态切换、一多适配类规则仅折叠屏支持检出）
3. **结果核对**：等待测试结束，查看检测报告：
   - case-a/b/c：预期 11 条规则各至少 1 次命中
   - case-d：预期 S1 截断 / S2 键盘遮挡 / S3 组件重叠 3 类场景各至少 1 次命中
4. **本地预检（可选）**：DevEco Studio 中用本机 Pura X Max 模拟器镜像（API 26）跑一遍各页面，确认违规现象仍在，再上传云测
